# Zadrya

Zadrya is a harm reduction journal for iOS and Android. It is free, open source (GPL-3.0-or-later), and no data ever leaves the device.

- **Absolute privacy**: no accounts, no server, no telemetry, no third-party SDKs.
- **Free forever**: no purchases, no ads, no locked features.
- **Non-judgmental harm reduction**: inform, never lecture.
- **Offline first**: fully functional without a connection.

The name comes from Zarya (Zorya), the dawn in Slavic mythology: the guardian of the passage from night to day.
